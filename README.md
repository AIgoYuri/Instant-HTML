# Instant-HTML 工具箱导航

这是一个极简的本地 HTML 工具箱管家。零配置，纯本地运行，随用随开。

### 🚀 快速上手 (How to Use)

1. **一键启动**：直接双击运行 `Runme.bat`，即可自动生成导航页并在浏览器中打开。
2. **自动分类**：将你的 HTML 工具扔进任意子文件夹（例如新建 `Tools_Box` 或 `Tools_Box_B`），脚本会自动识别并按文件夹名称进行分类。
3. **隐藏侧边栏**：点击页面左上角的“☰ 菜单”按钮，即可一键隐藏/展开侧边栏，专注使用工具。

### ✨ 核心特性 (Features)
* **动态生成**：添加新工具后，再次双击 `Runme.bat` 即可刷新列表。
* **自带搜索**：内置搜索框，秒速定位你需要的工具。
* **零依赖**：纯 HTML/CSS/JS 编写，无需配置服务器环境，发给谁都能直接用。

# Instant-HTML Toolbox Navigator

A minimalist, portable HTML toolbox manager. Zero configuration, runs entirely locally.

### 🚀 Quick Start

1. **One-Click Launch**: Simply double-click `Runme.bat`. It will generate the navigation page and open it in your browser automatically.
2. **Auto-Categorization**: Drop your HTML utility files into any subfolders (e.g., `Tools_Box`, `Tools_Box_B`). The script will automatically recognize and group them by folder name.
3. **Toggle Sidebar**: Click the "☰ Menu" button on the top left to hide or show the sidebar for a distraction-free view.

### ✨ Key Features
* **Dynamic Updates**: Added a new tool? Just run `Runme.bat` again to update the index.
* **Built-in Search**: Quickly find the tool you need using the top search bar.
* **Zero Dependencies**: Built with pure HTML/CSS/JS. No server required, works right out of the box anywhere.
