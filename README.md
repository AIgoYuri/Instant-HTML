# Instant-HTML 工具箱导航

这是一个零配置、便携式的 HTML 工具箱。只需将您的 HTML 工具文件放入任意子文件夹中，运行 BAT 脚本，即可自动生成一个分类导航页面，让您轻松管理和使用所有工具。

## 功能特性

*   **自动扫描**: 自动扫描所有子文件夹中的 `.html` 文件，并将其添加到导航。
*   **分类显示**: 工具按其所在的文件夹进行分类显示，结构清晰。
*   **动态生成**: 每次运行 `Runme.bat` 都会生成最新的 `index.html`，无需手动更新。
*   **一键运行**: 双击 `Runme.bat` 即可启动，自动在浏览器中打开导航页面。
*   **内置搜索**: 通过搜索框快速找到您需要的工具。
*   **侧边栏切换**: 点击左上角"☰ 菜单"按钮可隐藏/显示侧边栏，优化查看体验。
*   **零外部依赖**: 纯 HTML/CSS/JS，无需服务器环境，打开即用。

## 如何使用

1.  **放置工具**: 将您的 HTML 工具文件（`.html` 格式）放置到此目录下的任何子文件夹中。
2.  **运行脚本**: 双击根目录下的 `Runme.bat` 文件。
3.  **浏览工具**: 自动生成的 `index.html` 将在浏览器中打开，显示所有分类好的工具。

## 添加新工具

只需将新的 HTML 文件添加到现有的或新的子文件夹中，然后再次运行 `Runme.bat`。

## 隐藏侧边栏

在导航页面中，点击左上角的"☰ 菜单"按钮即可隐藏或显示侧边栏。

# Instant-HTML Toolbox Navigator

This is a zero-configuration, portable HTML toolbox. Simply drop your HTML utility files into any subfolders, run the BAT script, and a categorized navigation page will be automatically generated.

## Features

*   **Automatic Scanning**: Automatically scans all subfolders for `.html` files and adds them to navigation.
*   **Categorized Display**: Tools are displayed categorized by their folders.
*   **Dynamic Generation**: `index.html` is generated each time `Runme.bat` is run.
*   **One-Click Run**: Double-click `Runme.bat` to launch and open in browser.
*   **Built-in Search**: Quickly find tools using the search bar.
*   **Toggleable Sidebar**: Click "☰ Menu" button to hide/show sidebar.
*   **Zero Dependencies**: Pure HTML/CSS/JS, no server needed.

## How to Use

1.  **Place Tools**: Put HTML files in any subfolder.
2.  **Run Script**: Double-click `Runme.bat` in root directory.
3.  **Browse**: The generated `index.html` will open in browser.

## Adding New Tools

Just add new HTML files to subfolders and run `Runme.bat` again.

## Hiding Sidebar

Click the "☰ Menu" button to hide or show the sidebar.
